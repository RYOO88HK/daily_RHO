러닝화 선택 가이드

1️⃣ 프로나이션 (발의 회전, 보행 패턴)

  • 발이 안쪽으로 기우는 오버프로나션 → 안정성(stability) 신발 추천
  • 중립(neutral) 보행 → 일반 쿠셔닝 신발 무난
  • 발이 바깥쪽으로 기우는 언더프로나션 → 충격 흡수 좋은 쿠션 신발 추천
  • 발 마모 패턴, wet test로 프로나이션 확인 가능

2️⃣ 신발 종류

  • 쿠셔닝 신발: 충격 흡수 좋고 자연스러운 보행 지원
  • 안정성 신발: 약간의 보정 필요 시, 미드솔 안쪽이 단단함
  • 모션 컨트롤 신발: 심한 오버프로나션 시 추천

3️⃣ 발 사이즈 & 핏

  • 좌우 발 크기 다를 수 있음 → 필요 시 한 켤레씩 맞춤
  • 발가락 공간(toebox)이 충분히 있는지 확인
  • 하루 중 발이 가장 부었을 때 사이즈 체크 권장

4️⃣ 주행 거리 / 용도 고려

  • 마라톤이나 장거리 러닝 → 쿠션 많은 신발 추천
  • 트레일 러닝 → 접지력 좋은 트레일화 필요

5️⃣ 신발 교체 주기

  • 미드솔 쿠션은 마일리지 따라 줄어듦 → 400~600마일마다 교체 권장
  • 밑창 마모 또는 통증 발생 시 교체 고려

6️⃣ 추천 러닝화 모델 예시

  • Nike Pegasus 41: 로드 러닝용, 초보자/중급자 모두 무난
  • Adidas Adizero Boston 13: 경량, 레이싱/빠른 훈련용
  • 코오롱스포츠 TL‑1: 트레일 러닝, 접지력 우수
  • Under Armour Sonic 7: 일상 러닝, 편안하고 내구성 좋음
  • Nike Pegasus 41 Women: 여성용, 발 모양 맞춤
  • Revonix Carbon BalanceA: 경량, 퍼포먼스 + 스타일

7️⃣ 러닝화 선택 팁

  • 처음 시작할 땐 너무 기술적 신발보다는 기본 + 쿠션 많은 모델 추천
  • 매장에서 직접 걸어보고 뛰어보는 것이 가장 중요
  • 온라인 구매 시 반품/사이즈 교환 여부 확인 필수
  • 러닝화 두 켤레를 번갈아 사용하면 쿠션 회복에 도움
